# TP2-G5-A1 — Parabolic Scaling Audit

Under u_lambda(x,t)=lambda u(lambda x,lambda^2 t), with standard Brownian
rescaling:

| Quantity | Weight |
|---|---:|
| A, S, Omega | lambda^2 |
| omega | lambda^2 |
| G=J_omega | lambda^3 |
| D | lambda^0 |
| Y=DG | lambda^3 |
| C_ell=D partial_ell G | lambda^4 |
| B_Y | lambda^5 |
| N | lambda^6 |
| R | lambda^4 |
| b_N | lambda^8 |
| sigma_N | lambda^7 |
| b_R | lambda^6 |
| sigma_R | lambda^5 |
| Xi=N/R | lambda^2 |
| b_Xi | lambda^4 |
| sigma_Xi | lambda^3 |

Thus [Xi]=lambda^2 and [dXi/dtau]=lambda^4. Every quotient drift term,
including N-R covariation and the denominator Ito correction, has weight
lambda^4. The statement concerns a scaling family; it does not identify a
fixed torus with its dilated domain.
