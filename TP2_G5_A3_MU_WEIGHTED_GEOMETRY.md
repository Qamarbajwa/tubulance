# TP2-G5-A3 — Mu-Weighted Geometry

For a probability measure `mu` supported on the nonzero-vorticity and nonzero-deformation domain,

`E_mu[Xi] = E_mu[M_D] + E_mu[C_D]`.

This is an expectation of a Lagrangian/deformation-weighted observable. It is not an Eulerian spatial average merely because `Xi` contains spatial derivatives. If `d mu = rho dP`, then the weight `rho` remains part of every term; changing from `mu` to a spatial measure is a substantive theorem obligation, not notation.

The A3 package establishes no closure for `E_mu[M_D]`, `E_mu[C_D]`, or `E_mu[Xi]` from Eulerian enstrophy, analyticity, coherence, sparseness, or inverse-length data alone.
