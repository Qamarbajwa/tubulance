# TP2-G5-A2 — Ito Compensation Audit

The square-completed term is
\[
I_\Xi=\frac{2\nu}{R}\sum_\ell
\left\|H_\ell-\frac{2c_\ell}{R}Y\right\|_F^2.
\]
It is nonnegative for every stopped state R>0 and vanishes exactly when
\[
H_\ell=\frac{2c_\ell}{R}Y\quad\forall\ell.
\]
If Y=0, this reduces to H_ell=0 for every ell. Otherwise every spatial
derivative matrix H_ell must be collinear with Y, with a coefficient fixed by
the Z-to-column contraction c_ell. This is an overdetermined instantaneous
jet compatibility condition, not a proven invariant manifold and not known
to be dynamically realizable.
The condition is added to the open joint-jet realization question. No
regularizing interpretation is assigned to nonnegativity alone.
